# Math Warrior

A browser-based math battle game where your hero defeats monsters by answering arithmetic questions correctly.

## How to play

1. Open `index.html` in any modern browser.
2. Click **Start Battle**.
3. Answer each math question before the enemy attacks.
4. Correct answers deal damage; wrong answers hurt the hero.
5. Defeat enemies, level up, and keep the score climbing.

## Files

- `index.html` – page structure
- `style.css` – visual theme and layout
- `script.js` – game logic and question generation

## Notes

This is a simple, self-contained HTML/CSS/JavaScript game and does not require any build setup.
